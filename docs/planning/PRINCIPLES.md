# 产品与维护原则

## 定位

Agent Comm 为用户正在运行的 agent 提供通信与协作组件。README 给用户明确入口，根 SKILL 给 agent 可执行的安装/更新说明，Go helper、Python runtime 和宿主适配器分别承担通信、协作规则与原生执行。

## 易用性与宿主适配

安装说明应让 agent 能从当前环境判断路径、版本和配置。接收消息、工具执行及需要主人确认的操作使用宿主原生机制；消息送达不意味着宿主自动唤醒或任务自动完成。

## 仓库边界

SDK 提供客户端协议和 runtime；Platform 提供公共通信设施；Web/iOS 提供人的使用入口；部署仓库管理整套服务发布。适配器按宿主分目录，公共 Go imports 与根安装 skill 路径保持稳定。

## 发布与文档

通过 GitHub Release 分发 helper、校验和、manifest 和安装文档。文档必须区分已实现行为与未完成设想；历史方案由 Git 历史保留，现役文档只描述当前可维护内容。
